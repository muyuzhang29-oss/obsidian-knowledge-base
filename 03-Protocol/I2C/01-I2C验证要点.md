# 01-I2C验证要点

> [!abstract] 用途
> I2C master/slave VIP 与 IP 验证清单。协议说明见 [[03-Protocol/I2C/00-I2C]]。

---

## 1. 必备知识点

| 概念 | 要点 |
|------|------|
| SCL/SDA | 开漏 + 上拉，线与 |
| 起始/停止 | SCL 高时 SDA ↓=START，↑=STOP |
| 字节格式 | 7-bit 地址 + R/W，或 10-bit |
| ACK/NACK | 第 9 个 SCL 周期 |
| 时钟拉伸 | slave 拉低 SCL 等待 |
| 多字节读 | Repeated START |

```text
START | A6..A0 | R/W | ACK | DATA[7:0] | ACK | ... | STOP
```

---

## 2. 用例矩阵

| # | 类别 | 用例 |
|---|------|------|
| I1 | 寻址 | 7/10-bit，广播 0x00 |
| I2 | 方向 | 写 / 读 / 写读（RS） |
| I3 | 长度 | 1..N 字节、单字节 |
| I4 | ACK | 全 ACK / 中途 NACK / 无 slave |
| I5 | 时钟拉伸 | 短/长 stretch，SCL 低电平保持 |
| I6 | 仲裁 | 双 master 同拍 START（multi-master） |
| I7 | 异常 | STOP 早发、SDA 复位、SCL 卡低 |
| I8 | 速率 | SM 100k / FM 400k / FM+ |
| I9 | 滤波 | 毛刺、SDA setup/hold |
| I10 | FIFO/IRQ | rx/tx 水位、done 中断 |

---

## 3. 时序参数（验证要盯）

```text
t_HD;STA  起始保持
t_SU;STA  起始建立
t_HD;DAT  数据保持
t_SU;DAT  数据建立
t_LOW / t_HIGH   SCL 低/高宽度
t_BUF     STOP→START
```

> [!warning] 
> 数据手册参数往往用 ns 级；仿真里用 `timeunit` + 半周期约束；scoreboard 采样点在 **SCL 高电平中点**。

---

## 4. Monitor / 参考模型

```systemverilog
// 边沿重构字节：SCL 上升采 SDA
function void sample_byte();
  if (bit_cnt == 8) begin
    addr = shift;
    ...
  end
  if (bit_cnt == 9) ack = sda;
endfunction
```

Scoreboard：**字节流 + ACK 图** 与 RAL/业务期望比对；NACK 路径单独分支。

---

## 5. SVA / 协议稳定

```systemverilog
// SCL 高期间 SDA 只允许在 START/STOP 边沿跳变
a_stable_data: assert property (
  @(posedge scl) (state == DATA) |-> $stable(sda) throughout (1'b1)
);

// ACK 只在第 9 个周期驱动
```

更实用：用 **事务级 checker** 检查字节边界与 ACK 位置。

## 6. 覆盖

```systemverilog
cp_addr7   : coverpoint addr[6:0];
cp_dir     : coverpoint rw;
cp_len     : coverpoint nbytes { bins one={1}; bins mid={[2:4]}; bins long={[5:16]}; }
cp_ack     : coverpoint ack_pattern; // 全ACK/末NACK/首NACK
cp_speed   : coverpoint scl_rate;
x_dir_len  : cross cp_dir, cp_len;
```

---

## 7. 常见 bug

| 症状 | 原因 |
|------|------|
| 地址对、数据错位 | 起始/重复起始未复位位计数 |
| 偶发 NACK | setup/hold 不足、时钟拉伸未支持 |
| 多 master 总线卡死 | 仲裁丢失后未释放 SDA |
| 读提前 STOP | 状态机在第 N 字节误判 |
